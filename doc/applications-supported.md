# Supported Applications

The eviDense UV Photometer supports automated UV absorbance measurements as part of liquid handling workflows. 
The instrument performs the optical measurement and returns the raw measurement data to the host system.
The HSE API processes these raw measurement values to calculate UV absorbance and application-specific results, such as nucleic acid concentrations and purity ratios. 

The following applications and results are currently supported:

## Nucleic Acids
- Double-stranded DNA (dsDNA): Concentration measurement and 260/230 and 260/280 purity ratios
- Single-stranded DNA (ssDNA): Concentration measurement and 260/230 and 260/280 purity ratios
- RNA: Concentration measurement and 260/230 and 260/280 purity ratios

## Further Applications
Further applications that can be measured based on UV absorbance, such as protein quantification, can also be performed with the eviDense UV Photometer. 
These applications have been pre-tested for selected workflows but are not yet part of the fully tested application scope.
