# Liquid Handler Requirements

This page describes the requirements a liquid handler must meet to operate with
eviDense UV Photometer.

## Mechanical Requirements

The platform should be able to:

- pick up and hold the disposable cuvette reliably
- move to the taught eviDense positions repeatably
- insert and remove the cuvette in a controlled way
- discard used cuvettes safely after measurement

## Workflow Requirements

The workflow should be able to:

- keep the intended measurement order of blanks and samples
- coordinate liquid handling with the measurement sequence and timing
- check that the guide is empty before inserting a new cuvette
- respond appropriately to warnings or unexpected run conditions

## Software and Data Requirements

The system should also be able to:

- run or call one of the supported eviDense UV Photometer software interfaces
- retain result files or pass result data to host software
